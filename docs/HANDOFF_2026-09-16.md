## 2. 완료한 것과 근거

### 2-1. 제3자 리뷰 (GitHub Copilot CLI)

`npm i -g @github/copilot`로 설치하고 **저장소 복사본**(스크래치)에서 읽기 전용 평가를 돌렸다 — 원본을 건드리지 않기 위해서다.
인증은 기존 `gh` 토큰(`GH_TOKEN`)으로 됐다. 지적 중 **네 개를 코드로 직접 대조**했다.

### 2-2. 차량 하위 REST 소유권 검사 (ADR-025)

- **규칙**: 관리자는 등록된 활성 차량 전부, 그 외 사용자는 자기 소유 차량만 — WebSocket이 쓰던 판정 그대로.
- `VehicleAccessInterceptor`를 `/api/vehicles/*`·`/api/vehicles/*/**`에 건다. **컨트롤러마다 넣지 않는다** — 새 엔드포인트에서 조용히 빠지는 것이 이 문제의 원인이었다.
- **거부는 404**(403은 "그 차량은 존재한다"를 알려준다).
- 목록은 서비스가 소유자로 자르고(`findAllVisibleTo`), 등록은 비관리자가 남의 이름으로 못 한다(403, 차량 ID 선점 방지).
- **인터셉터 순서는 rate limit 뒤** — 앞에 두면 Redis 장애 실험(`load-test/redis-outage`)이 재던 fail-open/fail-closed 경로가 달라진다.
- 테스트: `VehicleAccessControlTest` 5건(서비스가 호출되지 않는 것까지 검증), `VehicleServiceTest` 소유권 2건, 기존 슬라이스 3개 보정.
