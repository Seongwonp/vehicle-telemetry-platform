## 3. 결정 대기

1. **SIM-003 등록 여부** — 시뮬레이터 차량이지만 `vehicles`에 없어 새 필터에서 숨겨진다(앱에서도 원래 안 보임). 보이게 하려면 대시보드 예외가 아니라 등록이 맞다.
2. **`GRAFANA_PG_READER_PASSWORD` 영구화** — 지금 실행 중이던 grafana는 셸로 넘긴 임의 값을 썼다(저장소 밖 세션 임시 파일). `.env`에 값이 없으면 grafana 재생성 시 변수가 비어 **5개 패널이 빈 화면**이 된다(실험 차량이 섞이지는 않음). 영구화: `.env`에 값 → `sh scripts/grafana-pg-reader.sh` → `docker compose ... up -d --no-deps grafana`.
3. **실차 계획의 연결 결정**(계획 문서 "결정 대기"): SAN 없는 서버 인증서의 호스트 검증(hosts 파일 `mosquitto` 매핑 — 검증 끄기 금지), 차량 ID·인증서(폐기된 SIM-024·088 금지, CN = vehicle_id), MQTT 3.1.1 vs 5, ML 오프라인 채점 도구 부재.
